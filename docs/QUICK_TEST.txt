# 🧪 Teste Rápido - Docker Setup

## 5 Passos Para Validar Tudo em Menos de 1 Minuto

### **Passo 1: Verifique os Arquivos**
```powershell
Test-Path "D:\Projects\Dotnet\RaqNRollPlayground\Dockerfile"
Test-Path "D:\Projects\Dotnet\RaqNRollPlayground\docker-compose.yml"
Test-Path "D:\Projects\Dotnet\RaqNRollPlayground\docker-start.ps1"
```
✅ Todos devem retornar `True`

---

### **Passo 2: Verifique a Imagem Docker**
```powershell
docker images | Where-Object {$_ -like "*financial-api*"}
```
✅ Deve mostrar: `financial-api  latest  380MB`

---

### **Passo 3: Valide docker-compose**
```powershell
cd "D:\Projects\Dotnet\RaqNRollPlayground"
docker-compose config --services
```
✅ Deve mostrar:
```
postgres
api
```

---

### **Passo 4: Inicie os Containers**
```powershell
docker-compose up -d
```
✅ Aguarde ~20 segundos pelo health check

---

### **Passo 5: Verifique o Status**
```powershell
docker-compose ps
```
✅ Deve mostrar ambos os containers `Up`:
```
financial_control_postgres   Up (healthy)   ...
financial_control_api        Up             ...
```

---

## ❌ Se Algo Não Funcionou

### **Problema: Imagem não existe**
```powershell
# Reconstrua
docker-compose build --no-cache
```

### **Problema: Port já em uso**
```powershell
# Parar containers anteriores
docker-compose down

# Ou mudar porta no docker-compose.yml
# Altere "8080:8080" para "8081:8080"
```

### **Problema: Containers não iniciam**
```powershell
# Ver detalhes
docker-compose logs

# Limpar e recomeçar
docker-compose down -v
docker-compose up -d
```
